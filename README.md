Multi-User PDF Viewer Application

📝 Project Description

The Multi-User PDF Viewer Application is a desktop-based software developed using Python, Tkinter, and CustomTkinter that allows users to securely view, navigate, and manage PDF documents. The application supports multiple user accounts, ensuring that each user can maintain their own personalized bookmarks for different PDF files.

The system provides an interactive and user-friendly graphical interface with essential PDF viewing features such as page navigation, zooming, and direct page access. Users can bookmark important pages and quickly return to them later, improving productivity and ease of document handling.

User authentication and bookmark data are stored using an SQLite database, making the application lightweight, fast, and portable. The application is packaged as a standalone Windows executable (EXE), allowing it to run without requiring Python installation.

✨ Key Features

🔐 User Registration & Login System
👥 Multi-User Support with Individual Bookmarks
📂 Open and View PDF Files
⏭️ Page Navigation (Next, Previous, Go to Page)
🔖 Add, View, and Delete Bookmarks
🔍 Zoom In / Zoom Out with Mouse & Buttons
🧭 Keyboard Shortcuts for Navigation
🗃️ SQLite Database for Persistent Storage
🎨 Modern UI using CustomTkinter
📦 Packaged as a Standalone Windows EXE

🛠️ Technologies Used

Programming Language: Python
GUI Framework: Tkinter, CustomTkinter
PDF Handling: PyMuPDF (fitz)
Database: SQLite
Image Processing: Pillow (PIL)
Executable Packaging: PyInstaller

🎯 Objective

The objective of this project is to create a secure, user-friendly, and efficient PDF viewing application that supports multiple users and personalized bookmarks, while maintaining a modern graphical interface and portability.

🚀 Applications

Academic document reading
E-books and notes management
Office and research document review
Personal PDF organization
